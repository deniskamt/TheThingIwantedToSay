# Один вопрос

Розово-белая страничка с сердечками и одним вопросом.
Кнопка «Нет» убегает от курсора (и от пальца на телефоне) — нажать её нельзя.
При нажатии «Да» появляется ответная надпись и салют из сердечек.

Текст задаётся **переменными окружения**, так что на Railway его можно менять
через Variables, не трогая код.

## Деплой на Railway

1. **New Project → Deploy from GitHub repo** и выбери этот репозиторий.
2. Railway сам определит Node (Nixpacks) и запустит `npm start`. Ничего
   настраивать не нужно: порт берётся из `PORT`, healthcheck — `/healthz`.
3. Открой сервис → **Settings → Networking → Generate Domain**, чтобы получить
   публичную ссылку.
4. Открой **Variables** и задай тексты (см. таблицу ниже). После сохранения
   Railway передеплоит сервис сам.

## Переменные

| Переменная   | Что это                    | По умолчанию                     |
|--------------|----------------------------|----------------------------------|
| `QUESTION`   | Текст вопроса              | `Варя, признай: я самый лучший?` |
| `ANSWER`     | Надпись после нажатия «Да» | `я так рад что ты это признала`  |
| `YES_LABEL`  | Подпись кнопки «да»        | `Да`                             |
| `NO_LABEL`   | Подпись убегающей кнопки   | `Нет`                            |
| `PAGE_TITLE` | Заголовок вкладки браузера | `Один вопрос`                    |

Любую можно не задавать — тогда возьмётся значение по умолчанию.
Значения подставляются на сервере при каждом запросе и экранируются, так что
кавычки, `&` и угловые скобки в тексте безопасны.

## Запуск локально

```bash
npm start                      # http://localhost:3000
QUESTION="Свой вопрос?" npm start
```

Зависимостей нет — нужен только Node 18+.

## Структура

```
server.js           крошечный HTTP-сервер: читает env и отдаёт страницу
public/index.html   сама страница (вёрстка, сердечки, логика кнопок)
railway.json        конфиг деплоя (start command + healthcheck)
.env.example        список переменных
```
