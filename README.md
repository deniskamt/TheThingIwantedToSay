# Один вопрос

Розово-белая страничка с сердечками и одним вопросом.
Кнопка «Нет» убегает от курсора (и от пальца на телефоне), нажать её нельзя.
При нажатии «Да» появляется ответная надпись и салют из сердечек.

## Как открыть

Просто открой `index.html` в браузере — никаких зависимостей нет.

## Как поменять текст

В `index.html` в самом начале блока `<script>`:

```js
const QUESTION = "Варя, признай: я самый лучший?";
const ANSWER   = "я так рад что ты это признала";
```
